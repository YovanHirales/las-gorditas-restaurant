# Las Gorditas LV

A restaurant website built for Las Gorditas, a local Mexican restaurant in Las Vegas, NV.

**All visual design including layout, colors, and imagery, was provided and directed by the restaurant owners. Implementation followed their specifications.**

Live site: [www.lasgorditaslv.com](http://www.lasgorditaslv.com)

## Pages

- **Home** — Landing page with hero section and overview
- **Menu** — Full menu with food photos
- **Our Story** — Background on the restaurant
- **Photos** — Photo gallery
- **Contact** — Contact form powered by EmailJS

## Tech Stack

- React
- React Router
- EmailJS (contact form)
- Deployed via GitHub Pages

## Run Locally

```bash
npm install
npm start
```
